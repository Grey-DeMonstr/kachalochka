# Future features

Features that are agreed but not built yet. A feature marked **Requires Design** needs screens
from the design project before work starts.

## Comments on a plan and on its machines — Requires Design

A plan gets a comment of its own, and each machine in the plan gets a comment too. When a plan
becomes a visit, the visit shows these comments: the plan's comment for the visit, and each
machine's comment on that machine. A trainer uses them to tell the trainee how to do the
workout; anyone who plans for themselves can use them as well.

## Results while planning — Requires Design

While a plan is made, each machine in it shows the best result on it and the latest three
results with their dates. A trainer sees the trainee's results; anyone who plans for themselves
sees their own.

- The rest timer can play a sound when it ends.
- Fixed: with several children, only the first one can be chosen in the set form.
- Fixed: a set recorded for a child creates an unlinked copy of the machine.

- Share a visit as text from the visit screen.

1.0.2

- Groups of friends: create a group, invite friends with a link or a code, and see each other's

  other's results on it, and either of you can unlink it.
- One visit per day: the home screen opens today's visit, with no start or end.
- Moving a visit onto a day that already has one offers to replace it.
- Change the order of machines and sets in a visit with the order button.
- A list of all your machines on the home screen, to add or edit them.
- A set's weight and a machine's weight step can be typed in, with decimals.
- Machines can use an own unit, such as plates, with its name shown next to every weight.
